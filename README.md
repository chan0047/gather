# Gather

Having trouble organising a gathering with friends? Gather helps your group
pick times and activities that work for everyone.

## Getting Started

Follow these steps to run Gather locally.

1. Clone the Gather repository.
2. Open a terminal in the project folder and run `npm install`.
3. Run `npm run dev` to start the development server.
4. Open [http://localhost:3000/](http://localhost:3000) in your browser.

## What works today

Click **Plan name** or the text field to type a plan name.

After typing a plan name, select **Create plan** or press **Enter** while
the text field is focused.

A valid name shows a confirmation below the form while submitting a blank
name or a name with only spaces shows an error.
